## Decisions
- The skill's source lives in the brain folder (skill/), linked into ~/.claude/skills/brain.
  why: the skill and the brain it serves evolve together in one place
  not: a separate skill folder under ~/.agents/skills
- The skill finds the brain folder as the folder it lives in; `$BRAIN_REPO` overrides when set.
  why: nothing to configure, and the skill can still point elsewhere when needed
  not: a required environment variable; a hard-coded path
- Dump never fetches the source; its summary comes from what the user gave and what the session knows.
  why: the user is mid-work and must not wait; reading sources is prep work at pull
  not: fetching links at dump time
- Dump records `found_while` from the session, without asking.
  why: it is the context recall connects to later; asking costs attention
  not: asking the user why they saved it
- A verdict is given per dump and stored as its `status:`; released dumps never return to recall.
  why: one cluster can hold dumps with different fates; the dump file stays the single record of its state
  not: verdicts per cluster; deleting released dumps
- A parked dump records `when:` and returns only when that matches.
  why: parked means waiting for a better moment
  not: parked dumps resurfacing on every recall
- One golden note per thread, updated in place with a dated Trail line.
  why: the note always says what is true now, and the trail shows how thinking moved
  not: a new note per session
- A recall session opens by offering one or two prepared threads; the user picks, merges or names a topic.
  why: the agent prepares, the user drives
  not: the agent starting unasked; a list of saves
- brain.py only finds, lists and transcribes; judgment stays in SKILL.md.
  why: judgment belongs to the model and improves with it
  not: a script that clusters or scores dumps
- Session transcripts import golden.py's loader at run time.
  why: one extractor for both skills
  not: a vendored copy of the loader
- A recall transcript starts at the last bare `/brain` prompt; `--from N` overrides.
  why: `/brain <thing>` is a dump, not a recall start
  not: saving the whole session
- Context briefs carry gist, past conclusions, tension and questions to ask.
  why: the brief is the agent's prep for a user-driven conversation
  not: a plain list of sources
- The first yard item is the moved about_skills.md, with frontmatter added and content kept verbatim.
  why: seed the yard with a real dump
  not: leaving it at the repo root
